Added a Plugins page to Settings with the same two tabs as `/plugins`. Installed turns Claude Code and Grok Build plugins on or off, updates and uninstalls them, shows what each holds, and imports what Claude Code and Grok Build installed. Marketplace lists every known marketplace (Anthropic's and xAI's, the ones you added, and those Claude Code and Grok Build know) with its whole catalog, fetched in the background, and installs from it. A plugin is trusted only after a confirmation that lists what it runs.
