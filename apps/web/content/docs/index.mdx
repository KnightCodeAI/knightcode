KnightCode is an extensible AI agent that works from your terminal. Give it a goal and a working folder, and it can inspect files, run commands, edit content, and work through multi-step tasks.

Use KnightCode for software development, research notes, writing projects, data files, or hobby work. You can use KnightCode as is, prompt it to adapt itself to your workflow, or build other applications powered by KnightCode using the SDK.

## Start using KnightCode

New to KnightCode? Follow the [Quickstart](/docs/quickstart) to install KnightCode, connect a model, and complete your first task.

If KnightCode is already installed, choose what you want to do:

- [Use KnightCode interactively](/docs/run/usage) to add files, run commands, direct ongoing work, and export results.
- [Choose a model](/docs/run/models) or connect a subscription, API key, local model, or compatible endpoint.
- [Continue or branch a session](/docs/run/sessions) to resume work or explore another approach without losing history.

## Customize KnightCode

KnightCode can reuse prompts, load specialized instructions, add executable integrations, change its terminal interface, connect model services, and distribute these resources as packages.
Use the [Quickstart customization chooser](/docs/quickstart#choose-how-to-customize-knightcode) to select the smallest mechanism that meets your need.

## Work safely

KnightCode's tools and extensions run with the permissions of the KnightCode process. Project trust controls which project resources KnightCode loads, but it does not sandbox tool calls. Review [Security](/docs/run/security) before using untrusted files, repositories, extensions, or unattended automation.
