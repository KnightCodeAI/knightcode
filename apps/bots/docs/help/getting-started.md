# Getting started

A bot is an assistant with its own chat, memory, files and computer. Create one from the sidebar's New Bot button,
start from blank or a template, and give it a name and instructions.

- Your bots run on your own AI provider accounts. Connect them in Settings > General.
- Talk to a bot in its chat. It keeps working when you close the app; you get a notification when it needs you.
- Connect apps (mail, calendar, code, files) from Connect apps so a bot can use them.
- Choose how bots ask before acting in Settings > Approvals.
