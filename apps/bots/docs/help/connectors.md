# Connected apps

Connect Apps lists every app bots can use: the makers' own servers, KnightCode
plugins and a long tail of other apps, as one catalog. Connections belong to
you; each bot chooses which of them it uses, and asks before using a new one.

- Connecting an app can add its skills (one checkbox, ticked by default).
- A usage note tells bots how to use an app ("Always draft, never send").
- Reads and writes each have a permission: automatic, needs approval, or off.
- Some apps sign in through a service that holds their tokens; the connect
  screen says so.
