# Skills

A skill is written know-how a bot reads when it does that task: the steps, when
to use it, what to check and when to ask first. Only each skill's one-line
description sits in the bot's prompt until it is used.

- Your skills are every bot's; a skill a bot saves stays with that bot until you
  share it.
- After a multi-step task, ask the bot to save it as a skill.
- Teach a task: in the computer view, show the bot how by doing it once.
  Passwords go through Protected input, which is never recorded. Save the draft,
  and a routine can run it.
