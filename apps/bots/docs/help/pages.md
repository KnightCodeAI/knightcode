# Pages

Bots build pages: documents and live dashboards with text, tables, charts,
files, widgets and buttons.

- A widget reads its data straight from a routine's latest output, an app, or a
  file. It refreshes when its routine runs and never calls a model, so it costs
  no tokens.
- A button runs a routine, or an app action after your approval.
- Pages keep their versions; you can edit any page, and a bot edits only the
  pages it made.
