# Memory

Each bot keeps notes: one fact per note, with a name and a one-line description.
It sees the list of notes every time and recalls the relevant ones in full
before answering. Notes older than a day show their age.

- Read, download or delete notes in the bot's Library.
- "Share with all my bots" moves chosen notes to shared memory; notes that look
  private stay where they are.
- Old messages stay searchable: the bot can search and read its whole chat
  history.
- To bring memory from another assistant, use Import in the Library and paste
  its answer.
